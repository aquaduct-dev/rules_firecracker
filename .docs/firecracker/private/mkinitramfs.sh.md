## TL;DR
This script assembles a static, root-owned initramfs archive from a busybox binary, an init executable, and additional files.

It validates that the provided busybox and any ELF executables are statically linked, ensuring no dynamic loader is required at runtime. The script creates a temporary root filesystem structure, installing busybox with symlinks for all applets in `/bin` and specific utilities in `/sbin`. It copies user-specified files and executables to their absolute destinations within this tree. A standard `fstab` is generated to mount proc, sys, dev, tmp, and run filesystems. Finally, it packs the directory into a gzip-compressed cpio archive using busybox's own tools, enforcing a stable sort order and zeroing timestamps to ensure consistent output regardless of build environment.
